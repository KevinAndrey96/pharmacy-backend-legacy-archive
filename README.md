## 📌 Historical Overview

This repository preserves the historical AdonisJS REST API backend component originally developed for the Pharmacy E-Commerce Platform. It provided REST endpoints, authentication middleware, shopping cart sessions, and database schema migrations.

All components, database schemas, and workflows have been merged and modernized into the primary repository: **[pharmacy-ecommerce-platform](https://github.com/KevinAndrey96/pharmacy-ecommerce-platform)**.
